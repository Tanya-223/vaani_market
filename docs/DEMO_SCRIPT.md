# Vaani Market — demo recording script

**Audience:** you, recording the submission video (report §12.6). Two cuts: a 40-second
main and a 30-second short, both vertical, burned-in captions, two real speakers, real room
audio, no music over the voice. The voice is the evidence.

> Before recording: run `./run_web.sh`, open the cloudflared HTTPS link on the phone, and do
> the **Telugu review** first — every spoken line below is still a `reviewed:false` draft.

## The one thing to make the judges remember
Lead with the two things nothing else in this space does together: **it refuses to advise,
and it proves its numbers.** Show a refusal and a grounded "why did it move" with the chart.

## 40-second main cut (4 beats)

| Time | On screen | Speaker says (Telugu draft) | English caption |
|---|---|---|---|
| 0:00–0:08 | App open, mic tap | "క్యాండిల్ చార్ట్ అంటే ఏమిటి?" | "What is a candlestick chart?" |
| | Candlestick diagram + spoken answer | *(app answers from glossary + shows the labeled diagram)* | Beginner concept, answered out loud |
| 0:08–0:22 | Mic tap | "GAIL షేర్ ఈ రోజు ఎందుకు పడింది?" | "Why did GAIL move today?" |
| | Price + 30-day line chart; answer plays | *(app: price, % change, 30-day trend, then the honesty line)* | Live data + "I can't confirm the reason" |
| 0:22–0:32 | Mic tap | "HDFC బ్యాంక్ షేర్ కొనమంటారా?" | "Should I buy HDFC Bank?" |
| | Refusal card | *(fixed refusal plays — offers to explain instead)* | **Refuses to advise — by design** |
| 0:32–0:40 | Mic tap | "మరి దాని ట్రెండ్ ఎలా ఉంది?" *(follow-up, no company named)* | "And how's its trend?" |
| | Chart + answer | *(reuses the last ticker via memory)* | Remembers context; disclaimer always on screen |

Close on the screen showing **"విద్యా ప్రయోజనం కోసం మాత్రమే. ఇది సలహా కాదు."** (Educational only. Not advice.)

## 30-second short cut
Beats 2 (why-moved) + 3 (refusal) only — the grounded explanation and the refusal. That pair
is the whole pitch.

## Narration line for the caption/description
"Voice-first market explainer for Indian languages. It explains what happened and why — and
it refuses to tell you to buy or sell. Every number is traced to live data; the refusal is
hard-coded, not a prompt. Built on Gnani Prisma + Timbre."

## Safety checklist before you post
- [ ] Telugu lines reviewed by a Telugu speaker (remove `reviewed:false`).
- [ ] A refusal is shown on camera (the differentiator).
- [ ] The as-of date + "Not advice" line are visible in the frame.
- [ ] No real buy/sell suggestion anywhere in the cut.
